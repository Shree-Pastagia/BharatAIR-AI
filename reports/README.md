# BharatAIR Research & Technical Reports

This directory stores historical audit summaries, scientific design reports, and experimental configuration manifests generated across all development phases of the BharatAIR platform.

---

## Directory Organization

- **`audit_data/`**: Structured CSV and JSON datasets detailing sensor availability, historical station feasibility, multi-city period alignments, and cohort inclusion criteria across 107 CPCB stations.
- **`design_reports/`**: Formal methodological documents, validation result audits, cross-validation split window policies, and preflight feasibility verifications.
- **`experiment_configs/`**: JSON configuration files defining candidate models, hyperparameters, lookbacks ($L \in \{24, 48, 168\}$), and forecast horizons ($H \in \{1, 6, 12, 24\}$).
- **`screenshots/`**: High-resolution interface captures and validation curve plots.
